## 📌 Executive Summary

Every day, people travel, use electricity, eat meals, and generate waste. Most individuals and college campuses have no idea how much carbon these activities produce, or what practical steps they can take to reduce them.

**Carbon Coach** solves this by providing a conversational AI agent that:
1. **Understands plain language & intent:** Answers conceptual questions about climate change, renewable energy, and campus sustainability naturally, while reserving tool calls strictly for numerical activity calculations.
2. **Executes deterministic Python calculation tools:** Uses verified emission factors from the **Central Electricity Authority (CEA) of India** and **DEFRA / ARAI**. **Zero made-up numbers.**
3. **Maintains persistent session & conversation memory:** Remembers conversation context for follow-up comparisons (*"What if I took the metro instead?"*) and aggregate tracking (*"How did I do this week?"*).
4. **Delivers actionable, personalized tips:** Calculates exact CO₂e savings for every suggestion.
5. **Drives campus competition:** Real-time hostel & department leaderboard comparing per-capita emissions.
6. **Speaks local languages:** Full natural language support for **Telugu (తెలుగు)** and **Hindi (हिन्दी)** alongside English.

## 🚀 Hackathon Problem Statement Verification

### The Kickoff Example:
> *"I travelled 12 km by bus today and used the AC for 4 hours."*

Let's trace how Carbon Coach computes this:
1. **Tool 1:** `calculate_travel_emissions(mode="bus", km=12)`
   $$\text{Travel} = 12 \text{ km} \times 0.082 \text{ kg CO}_2\text{e/km} = \mathbf{0.984\text{ kg CO}_2\text{e}}$$
2. **Tool 2:** `calculate_electricity_emissions(appliance="ac", hours=4)`
   $$\text{Energy} = 1.2 \text{ kW} \times 4 \text{ hours} = 4.8 \text{ kWh}$$
   $$\text{Emissions} = 4.8 \text{ kWh} \times 0.713 \text{ kg CO}_2\text{e/kWh} = \mathbf{3.4224\text{ kg CO}_2\text{e}}$$
3. **Combined Total:**
   $$0.984 + 3.4224 = \mathbf{4.4064\text{ kg CO}_2\text{e}}$$
4. **Comparison:** 4.41 kg CO₂e is within the Paris Agreement 1.5°C daily budget (5.50 kg), but slightly above student campus average (3.80 kg).
5. **Actionable Saving:** Setting the AC to 24°C saves 24% energy ($\sim 0.82\text{ kg CO}_2\text{e/day}$).

## 🏆 Bonus Features Implemented

### 1. 🤝 Multi-Agent Architecture
- **Tracker Agent:** Parses natural language, extracts quantitative variables, invokes deterministic calculation tools, and updates session memory.
- **Coach Agent:** Evaluates trends, computes reduction potential, compares against benchmarks, and surfaces hostel rankings.
- **Root Agent:** High-level coordinator orchestrating conversation and language localization.

### 2. 🏆 Campus Mode & Leaderboard
- Students select their hostel (e.g. *Hostel Cauvery*, *Hostel Krishna*, *Hostel Godavari*, *Hostel Ganga*) or academic department (*CSE*, *ECE*, *Mech*).
- Live leaderboard ranks groups by **per-capita daily emissions** with badges (*🌿 Greenest Hostel*, *⚡ Solar Powered*).

### 3. 🧪 Golden Evaluation Cases (`pytest`)
- Comprehensive test suite in [`tests/test_golden_cases.py`](tests/test_golden_cases.py) with 13 tests covering edge cases, math assertions, and memory persistence.
- **100% pass rate in 1.8 seconds.**

### 4. 🗣️ Telugu (తెలుగు) & Hindi (हिन्दी) Support
- Automatic script and language detection.
- Natural, culturally resonant responses and explanations citing verified figures in Telugu and Hindi.

### 5. 🌐 Google Cloud Run Ready
- Optimized [`Dockerfile`](Dockerfile) with non-root user, slim Python 3.11 image, and `/health` probe.
- [`cloudrun.yaml`](cloudrun.yaml) service specification.
- One-click deployment scripts: [`deploy_cloud_run.sh`](deploy_cloud_run.sh) & [`deploy_cloud_run.bat`](deploy_cloud_run.bat).

## 🛠️ Getting Started

### Prerequisites
- Python 3.10+ (Tested on Python 3.11, 3.12, 3.15)
- (Optional) `GEMINI_API_KEY` from [Google AI Studio](https://aistudio.google.com/)

### 1. Clone & Install
```bash
git clone <repo-url>
cd "Carbon coach"

# Install dependencies
pip install -r requirements.txt
```

### 2. Run Golden Evaluation Tests
```bash
python -m pytest tests/test_golden_cases.py -v
```
Output:
```
tests/test_golden_cases.py::test_travel_emissions_bus_12km PASSED
tests/test_golden_cases.py::test_electricity_emissions_ac_4hours PASSED
tests/test_golden_cases.py::test_hackathon_challenge_statement_case PASSED
...
13 passed in 1.80s!
```

### 3. Launch Web Dashboard & Chat UI
```bash
python -m uvicorn carbon_coach.server:app --port 8080 --reload
```
Open **[http://localhost:8080](http://localhost:8080)** in your browser!

### 4. Run via Google ADK Developer CLI
```bash
python -m google.adk.cli run carbon_coach/agent.py
```
Or start the native ADK Web UI:
```bash
python -m google.adk.cli web carbon_coach/agent.py
```
